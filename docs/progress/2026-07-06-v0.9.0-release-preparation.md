## Purpose

This record closes the repository-side preparation and publication gates for the LAOS v0.9.0 source release. It does not introduce a deployment system, public service, package registry publication, desktop installer, or cloud runtime.

The release is a GitHub source release for the current local-first CLI, MCP, and Developer Bridge integration. Deployment is intentionally excluded because the repository has no defined production environment or deployable artifact target.

## Release scope

The v0.9.0 release includes:

- Markdown and JSONL authoritative memory storage with rebuildable SQLite FTS5 indexing;
- candidate-only memory creation and Review Gate-controlled activation;
- workspace, project, confidentiality, and restricted-content isolation;
- the unified 11-Agent JSON CLI;
- deterministic Reflection, Policy, candidate generation, and Loop Coordinator flows;
- conversation review and pluggable model backends;
- Agent Runtime, SessionStore, procedure lifecycle, Bridge event processing, and recovery;
- explicit MCP checkpoint capture and bounded read-only memory search;
- the fixed-scope Developer Bridge Adapter;
- macOS-first CI and acceptance evidence.

## Known limits

The release does not claim:

- passive or lossless browser-side ChatGPT capture;
- automatic policy approval or candidate activation;
- unattended background execution or retry;
- semantic vector search;
- multi-user authentication or owner/agent authorization;
- GUI, web frontend, desktop application, PyPI package, Homebrew formula, container image, or hosted service;
- Linux or Windows release support.
