## Purpose

(`deployment` remains `not_applicable`), same as v0.9.0.

## Release scope

Three feature streams merged since v0.9.0:

1. **Atomic vault promotion (Sliver 6 line, PR #36 + follow-ups)** —
   promotion claim state, failed-attempt audit, recovery inspection and
   decision rules, orphan promotion-source cleanup, plan abandonment,
   conflicted-candidate re-review, promotion-target reselection, and the
   vault writer ADR (ADR-001 Phase 2).
2. **Phase 4 evaluation foundation (S3.x)** — evidence composition pure
   functions (S3.2), independent evaluation entry point (S3.5), controlled
   with/without-memory experiments, Phase 4 design and planning documents.
3. **Phase 5 learning chain (S5.1–S5.4)** — comparison-lineage hardening,
   full adapter input integrity, deterministic evaluation identity
   (utility_evaluation schema v2), copy-only enrichment snapshot, producer
   composition-total integrity (S5.1a–e); deterministic reflection builder
   with dual-anchor lineage and 40-point tamper matrix (S5.2); eligibility
   with explicit 12-row FSM matrix and four fail-closed gates (S5.3, PR #37);
   immutable review-queue request producer and the persistence layer with
   typed zero-write preflight, no-replace atomic publish, crash-replay
   convergence, and E5 closure (S5.4, PR #38).

Hard boundaries unchanged: candidate-only creation, active memory via
Review Gate only, no queue consumption or decision writing (Human Review
Phase deferred), no LLM/generative claims in the deterministic chain,
macOS-first scope, Python >= 3.11.

## Known limits

- Queue requests are produced and persisted but never consumed by LAOS
  itself; disposition decisions belong to the deferred Human Review Phase.
- Persistence path-safety guarantees assume a single writer per state_dir
  and no external directory-tree mutation (TOCTOU defense is an explicit
  non-goal, recorded in the S5.4 plan).
- Linux/Windows support remains deferred; no cross-platform claims.
- Open PR #12 (bounded distillation context) is an independent line and is
  NOT part of this release.
