# LAOS v0.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal executable LAOS v0.8 kernel with Agent-only capabilities, routing-only orchestration, review-gated active memory, and deterministic restricted-safe context.

**Architecture:** The new modules adapt the existing validated Markdown memory system instead of creating a second store. The Registry selects five concrete Agents by exact task type; the Orchestrator only requests context, selects, calls, validates, and returns. Review Agent owns Review Gate, and legacy review commands route through that same path.

**Tech Stack:** Python 3.11+ standard library, existing Markdown/JSONL store, `unittest`, SQLite only through the existing rebuildable index.

**Repository rule:** Do not commit or push automatically. Every production change is followed by focused and complete test runs.

```python
class BaseAgent:
    agent_id = ""
    handles = []

    def can_handle(self, task):
        return isinstance(task, dict) and task.get("type") in self.handles

    def run(self, task, context):
        raise NotImplementedError

    def result(self, task, output, candidates=None, confidence=1.0):
        trace_id = deterministic_or_supplied_uuid(task)
        return {
            "agent_id": self.agent_id,
            "task_type": task["type"],
            "output": output,
            "candidates": list(candidates or []),
            "requires_review": True,
            "metadata": {"trace_id": trace_id, "confidence": float(confidence)},
        }
```

```python
class Orchestrator:
    def __init__(self, registry):
        self.registry = registry

    def run(self, task):
        if not isinstance(task, dict) or not isinstance(task.get("type"), str):
            raise ValueError("task.type is required")
        task_type = task["type"]
        context = {}
        if task_type != "context.build":
            context_task = {
                "type": "context.build",
                "input": {"task": task},
                "context_limit": task.get("context_limit", 8000),
            }
            context_agent = self.registry.select(context_task)
            context_result = context_agent.run(context_task, {})
            validate_result(context_result, context_agent, context_task)
            context = context_result["output"]
        target = self.registry.select(task)
        result = target.run(task, context)
        validate_result(result, target, task)
        return result
```

`src/orchestrator.py` only re-exports `Orchestrator`. The kernel imports no
memory, review, context, filesystem, SQLite, or import implementation.

- [ ] **Step 4: Implement lifecycle and read-only Store**

```python
STATES = {"raw", "candidate", "active", "deprecated", "conflicted", "archived"}
TRANSITIONS = {
    "raw": {"candidate"},
    "candidate": {"active", "archived", "conflicted"},
    "active": {"deprecated", "conflicted", "archived"},
}


class MemoryStore:
    def records(self):
        root, rows, errors, _ = legacy.collect_validated_records(self.root)
        if errors:
            raise ValueError("memory store validation failed")
        return [dict(item["record"], relative_path=item["relative_path"])
                for item in rows]

    def get(self, memory_id):
        for record in self.records():
            if record["id"] == memory_id:
                return record
        raise ValueError("memory not found")

    def active_relevant(self, query, workspace=None, project=None):
        terms = {term.casefold() for term in re.findall(r"[\w\u3400-\u9fff]+", query)}
        ranked = []
        for record in self.records():
            if record.get("status") != "active" or record.get("confidentiality") == "restricted":
                continue
            if workspace and record.get("workspace") != workspace:
                continue
            if project and record.get("project") not in {None, project}:
                continue
            haystack = " ".join(str(record.get(key, "")) for key in ("title", "content", "tags")).casefold()
            score = sum(term in haystack for term in terms)
            if score:
                ranked.append((score, record["id"], record))
        return [record for _, _, record in sorted(ranked, key=lambda row: (-row[0], row[1]))]
```

The Store has no public create, update, activate, or delete method. It filters
restricted and non-active records before relevance scoring.

- [ ] **Step 3: Implement four-action Review Gate**

```python
REVIEW_ACTIONS = {"accept", "reject", "merge", "conflict"}


class ReviewGate:
    def review(self, action, candidate_id, reason=None, legacy=False):
        if action not in REVIEW_ACTIONS:
            raise ValueError("unsupported review action")
        if action == "reject":
            args = argparse.Namespace(
                root=str(self.root), id=candidate_id,
                reason=reason or "rejected by reviewer",
            )
            return self.backend._reject_candidate_impl(args)
        if action == "conflict" and not legacy:
            return self._mark_conflicted(candidate_id)
        self._validate_candidate_action(action, candidate_id)
        args = argparse.Namespace(
            root=str(self.root), state_dir=str(self.state_dir), id=candidate_id,
        )
        return self.backend._accept_candidate_impl(args)
```

Conflict writes `conflicted`; the schema accepts both canonical `conflicted`
and legacy `conflict`, while old records are never rewritten automatically.

```python
class ContextBuilder:
    def build(self, query, limit=8000, workspace=None, project=None):
        if not isinstance(limit, int) or limit <= 0:
            raise ValueError("context limit must be positive")
        entries = self.store.active_relevant(query, workspace, project)
        text = ""
        sources = []
        for entry in entries:
            piece = render_entry(entry)
            separator = "\n\n" if text else ""
            remaining = limit - len(text)
            if remaining <= len(separator):
                break
            fitted = piece[: remaining - len(separator)]
            if not fitted:
                break
            text += separator + fitted
            sources.append(entry["id"])
            if len(fitted) < len(piece):
                break
        return {"text": text, "sources": sources, "limit": limit, "used": len(text)}
```

No timestamp, random value, inactive fallback, unrestricted flag, or full-store
fallback is present.
